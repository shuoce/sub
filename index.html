QUICK START

三步开始使用

根据你的客户端选择对应教程。

NekoBox / v2rayN

适用于 Android、Windows

1

打开客户端，进入「订阅管理」或「订阅设置」。

2

点击「添加订阅」，粘贴 NekoBox 订阅地址。

3

保存后点击「更新订阅」，选择节点即可使用。

Clash Meta / Mihomo

适用于桌面端与移动端

1

打开 Clash 客户端，进入「配置」页面。

2

添加远程配置，粘贴 Clash 通用订阅地址。

3

更新配置文件，并将其设置为当前配置。

FAQ

常见问题

订阅地址无法更新怎么办？

请先检查网络连接，然后确认复制的地址完整无误。仍无法更新时，可以尝试切换网络或稍后重试。

NekoBox 和 Clash 地址可以混用吗？

建议使用对应类型的订阅地址。NekoBox 地址通常适合 Base64/VLESS 客户端，Clash 地址适合 Clash Meta 或 Mihomo。

为什么需要定期更新订阅？

定期更新可以同步最新节点、配置和可用性信息，减少节点失效造成的连接问题。
